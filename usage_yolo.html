YOLO Master Studio 가이드

게임 매크로에 특화된 고성능 YOLO 학습 파이프라인.
데이터 수집부터 모델 내보내기까지, 올인원으로 해결하세요.

📊 Data Studio

게임 캡처, 데이터 증강, 자동 라벨링

🧠 Training Studio

YOLO11 학습, 모니터링, 모델 내보내기

시스템 요구사항

OS Windows 10/11 (64-bit)
GPU (필수) NVIDIA GeForce GTX 1060 이상 (VRAM 6GB+)
CUDA CUDA 12.1 또는 12.4 권장
RAM 16GB 이상 권장
Storage SSD 10GB+ 여유 공간
⚠️ 필수 요건: NVIDIA GPU와 CUDA가 반드시 필요합니다. AMD/Intel GPU는 지원하지 않습니다.

GPU 가속 설정 (CUDA)

GPU 가속은 학습 및 추론 속도를 10배 이상 향상시킵니다.

1
CUDA Toolkit 설치

NVIDIA CUDA Toolkit에서 12.1 또는 12.4 버전 다운로드 후 설치

nvcc --version # 설치 확인
2
cuDNN 설치

NVIDIA cuDNN 다운로드 (NVIDIA 계정 필요)

압축 해제 후 CUDA 설치 경로에 복사:
C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v12.x\

3
환경 검증

YOLO Master Studio 실행 시 자동으로 GPU 인식 여부를 확인합니다.

Data Studio 사용법

게임 화면을 캡처하고 학습 데이터를 준비하는 도구입니다.

주요 기능

  • 게임 캡처: 타겟 창 선택 후 단축키로 빠르게 캡처
  • ROI 설정: 캡처 영역을 게임창 일부로 제한
  • 데이터 증강: 회전, 색상 변환, 노이즈 등 자동 적용
  • 클래스 관리: 몬스터, 아이템 등 클래스 정의

자동 라벨링

AI가 게임 객체를 자동으로 인식하여 바운딩 박스를 생성합니다.

1
이미지 불러오기: 캡처한 이미지 폴더 선택
2
기본 모델 선택: 사전학습된 YOLO 모델로 초기 라벨링
3
검토 및 수정: 생성된 박스를 확인하고 필요시 수정
4
YAML 생성: 학습용 데이터셋 설정 파일 자동 생성

모델 학습

Training Studio에서 YOLO11 모델을 GUI로 간편하게 학습합니다.

학습 설정

모델 크기 Nano (빠름) / Small (균형) / Medium (정확) / Large (최고)
Epochs 100~300 권장 (데이터 양에 따라 조정)
Batch Size 8~16 (VRAM에 따라 조정)
Image Size 640 (기본) / 1280 (고해상도)
💡 Tip: 처음에는 Nano/Small 모델로 빠르게 테스트하고, 성능이 만족스러우면 더 큰 모델로 재학습하세요.

모델 내보내기

학습된 모델을 ONNX, TensorRT 형식으로 변환하여 추론 속도를 최적화합니다.

자주 묻는 질문 (FAQ)

Q. GPU가 인식되지 않습니다.

A. CUDA Toolkit과 cuDNN이 올바르게 설치되었는지 확인하세요. nvcc --version 명령이 작동해야 합니다. NVIDIA 드라이버도 최신 버전으로 업데이트하세요.

Q. 학습 중 CUDA Out of Memory 오류가 발생합니다.

A. Batch Size를 줄이거나 (8 → 4), 더 작은 모델 (Medium → Small)을 선택하세요. Image Size를 640으로 유지하는 것도 도움됩니다.

Q. TensorRT 변환이 실패합니다.

A. TensorRT 패키지가 설치되어 있는지 확인하세요: pip install tensorrt. CUDA 버전과 TensorRT 버전이 호환되어야 합니다.

Q. 학습된 모델을 SugarMacro에서 어떻게 사용하나요?

A. 내보낸 .pt 또는 .engine 파일을 SugarMacro의 설정에서 불러오면 됩니다. 자세한 내용은 SugarMacro 가이드를 참고하세요.
