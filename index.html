YOLO Master Studio 핵심 기능

게임 객체 학습을 위한 올인원 AI 도구

Data Studio

게임 화면 캡처, 자동 라벨링, 데이터 증강을 한 곳에서. AI가 바운딩 박스를 자동으로 생성합니다.

Training Studio

YOLO11 모델을 GUI에서 간편하게 학습. 실시간 Loss/mAP 그래프로 학습 상태를 모니터링하세요.

Model Export

학습된 모델을 ONNX, TensorRT로 변환하여 추론 속도를 극대화. 원클릭 내보내기 지원.

SugarMacro 핵심 기능

학습된 AI 모델을 활용한 지능형 게임 자동화

AI Vision Analysis

화면의 픽셀을 찾는 것이 아닙니다. YOLOv11 모델이 몬스터, 아이템, 지형을 실시간으로 인식하여 사람처럼 판단합니다.

Visual Node Editor

복잡한 코딩은 필요 없습니다. 직관적인 노드 에디터에서 흐름을 연결하기만 하면 나만의 로직이 완성됩니다.

Human-Like Interaction

기계적인 움직임을 배제합니다. 베지어 곡선(Bezier Curve) 기반의 마우스 이동과 무작위 딜레이로 사람과 구별할 수 없습니다.

Anti-Cheat Protection

하드웨어 레벨의 마우스/키보드 입력 에뮬레이션으로 완벽한 보안을 자랑합니다.
